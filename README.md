# 🧱 Microservices Auction Platform (.NET 8)

A simple auction platform built using a microservices architecture with Docker and .NET 8. This project includes:

- **Auction Service**
- **Search Service**
- **Identity Server**

## 🧰 Requirements
- [Docker](https://www.docker.com/)
- [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)

## 🚀 Getting Started

Follow these steps to run the project locally:

### 1. Start Docker Services (in Root Directory)
docker compose up -d

### 1. Run Micro Services (in AuctionService, SearchService, directory etc)
dotnet watch
